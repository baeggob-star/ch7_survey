# 📊 생성형 AI 활용 인식 설문 데이터 분석 앱

이 프로젝트는 부산대학교 인문사회계열 1학년 학생들의 '생성형 AI 활용 인식' 설문조사 결과를 정제하고, 그래프를 통해 시각적으로 분석하기 위해 만들어진 Streamlit 기반 웹 애플리케이션입니다. 

파이썬을 처음 배우는 학생들도 쉽게 이해하고 활용할 수 있도록 기능 단위로 코드가 구성되어 있습니다.

## 📁 폴더 및 파일 구조

프로젝트 폴더(`ch7_survey_app`)는 다음과 같이 구성해야 합니다.

```text
ch7_survey_app/
 ┣ 📜 Home.py                # 앱의 첫 화면 (메인 페이지)
 ┣ 📜 README.md              # 프로젝트 설명서 (현재 파일)
 ┣ 📜 requirements.txt       # 필요한 파이썬 패키지 목록
 ┗ 📂 pages                  # 멀티페이지 메뉴 폴더
    ┣ 📜 1_데이터_정제.py     # 1단계: CSV 데이터 전처리 및 정제
    ┗ 📜 2_그래프_분석.py     # 2단계: 정제된 데이터 기반 차트 분석
```

## 🛠️ 주요 기능

1. **데이터 정제 (1_데이터_정제.py)**
   * **CSV 업로드**: 구글 설문지에서 내려받은 원본 데이터를 불러옵니다.
   * **데이터 전처리**: 중복 응답 제거, 텍스트 표기 통일(학년, 단과대학), 이상치 처리(AI 사용시간 기준치 적용), 불성실 응답 및 결측치 관리 기능을 제공합니다.
   * **역문항 및 점수 계산**: 설문 문항 중 역문항(Q6)을 재계산하고, 'AI활용점수'와 'AI윤리의식' 평균을 자동 산출합니다.
   * **다운로드**: 정제가 완료된 데이터를 새로운 CSV 파일로 내려받을 수 있습니다.

2. **그래프 분석 (2_그래프_분석.py)**
   * **요약 지표**: 유효 응답자 수, 평균 사용 시간, 윤리의식 점수 등을 상단에 표시합니다.
   * **시각화**: Streamlit 기본 차트를 활용하여 응답자 구성(성별, 학년), 문항별 평균, 단과대학/학년별 집단 비교, 사용 시간과 점수 간의 분포(산점도)를 여러 탭에 걸쳐 쉽게 확인할 수 있습니다.

## 🚀 설치 및 실행 방법

1. **필수 패키지 설치**
   터미널(또는 명령 프롬프트)을 열고 프로젝트 폴더 경로로 이동한 뒤, 아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```

2. **앱 실행**
   설치가 완료되면 같은 터미널 창에서 아래 명령어를 입력하여 앱을 실행합니다.
   ```bash
   streamlit run Home.py
   ```
   명령어를 입력하면 기본 웹 브라우저가 열리면서 앱 화면이 나타납니다.
